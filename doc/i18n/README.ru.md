# Bells (BEL)

Bells - децентрализованная одноранговая система электронных денег, в которой
доказательство работы основано на алгоритме **scrypt**. Проект является форком
Litecoin: блоки по 2,5 минуты, пересчёт сложности в каждом блоке (DigiShield) и
общая эмиссия 500 000 000 BEL. Эталонный клиент 0.8.7.1 включает демон `bellsd`
и графический кошелёк `bells-qt`.

## Параметры сети

| Параметр | Значение |
| --- | --- |
| Доказательство работы | scrypt |
| Целевое время блока | 2,5 минуты |
| Пересчёт сложности | в каждом блоке (DigiShield) |
| Общая эмиссия | 500 000 000 BEL |
| Порт P2P (основная сеть) | 19919 |
| Порт RPC (основная сеть) | 19918 |
| Тестовая сеть (P2P / RPC) | 29919 / 29918 |
| Префикс адреса | `B` |
| Версия протокола | 70002 |
| Каталог данных (Windows) | `%APPDATA%\Bells` |
| Каталог данных (Unix) | `~/.bells` |
| Файл конфигурации | `bells.conf` |

## Быстрый старт в Windows

1. Скачайте `bells-0.8.7.1-win64.zip` или `bells-0.8.7.1-win32.zip` со страницы
   релизов.
2. Распакуйте архив в отдельную папку и держите все файлы вместе: без библиотек
   Qt и папки `platforms` кошелёк не запустится.
3. Запустите `bells-qt.exe` для графического кошелька или `bellsd.exe` для
   демона в командной строке.
4. Сделайте резервную копию `wallet.dat` до того, как использовать кошелёк с
   реальными средствами. Файл находится в `%APPDATA%\Bells`.

Демон останавливается по `Ctrl+C`. В Windows нет демонизации в стиле Unix,
поэтому параметр `-daemon` ни на что не влияет; используйте
`start /b bellsd.exe`.

## Конфигурация

Файл `%APPDATA%\Bells\bells.conf` поддерживает следующие параметры:

```ini
server=1
rpcuser=polzovatel
rpcpassword=smenite-menya
rpcallowip=127.0.0.1
rpcport=19918
port=19919
# addnode=1.2.3.4:19919
# listen=1
```

## Сборка из исходного кода

Проверенные версии: GCC 13.2 (MinGW-w64), Boost 1.83, Berkeley DB 4.8.30,
OpenSSL 1.0.2u, Qt 5.15.2 и встроенный LevelDB. Подробная документация на
английском языке:

* [Windows](../build-msw.md) - кросс-компиляция из Linux (x86_64 и i686)
* [Unix](../build-unix.md)
* [macOS](../build-osx.md)
* [Кошелёк Qt](../readme-qt.rst)

Berkeley DB 4.8 обязательна: более новые версии меняют формат файла
`wallet.dat`.
