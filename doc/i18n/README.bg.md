# Bells (BEL)

Bells е децентрализирана пиър-ту-пиър система за електронни пари, в която
доказателството за работа се основава на алгоритъма **scrypt**. Проектът е
разклонение на Litecoin: блокове на 2,5 минути, преизчисляване на трудността
във всеки блок (DigiShield) и обща емисия 500 000 000 BEL. Референтният клиент
0.8.7.1 включва демона `bellsd` и графичния портфейл `bells-qt`.

## Параметри на мрежата

| Параметър | Стойност |
| --- | --- |
| Доказателство за работа | scrypt |
| Целево време за блок | 2,5 минути |
| Преизчисляване на трудността | всеки блок (DigiShield) |
| Обща емисия | 500 000 000 BEL |
| P2P порт (основна мрежа) | 19919 |
| RPC порт (основна мрежа) | 19918 |
| Тестова мрежа (P2P / RPC) | 29919 / 29918 |
| Префикс на адреса | `B` |
| Версия на протокола | 70002 |
| Директория с данни (Windows) | `%APPDATA%\Bells` |
| Директория с данни (Unix) | `~/.bells` |
| Конфигурационен файл | `bells.conf` |

## Бърз старт под Windows

1. Изтеглете `bells-0.8.7.1-win64.zip` или `bells-0.8.7.1-win32.zip` от
   страницата с изданията.
2. Разопаковайте архива в папка и дръжте всички файлове заедно: без Qt
   библиотеките и папката `platforms` портфейлът не се стартира.
3. Стартирайте `bells-qt.exe` за графичния портфейл или `bellsd.exe` за демона
   от командния ред.
4. Направете резервно копие на `wallet.dat`, преди да използвате портфейла с
   реални средства. Файлът се намира в `%APPDATA%\Bells`.

Демонът се спира с `Ctrl+C`. Windows не поддържа демонизация като Unix, затова
опцията `-daemon` няма ефект; използвайте `start /b bellsd.exe`.

## Конфигурация

Файлът `%APPDATA%\Bells\bells.conf` приема следните настройки:

```ini
server=1
rpcuser=user
rpcpassword=change-me
rpcallowip=127.0.0.1
rpcport=19918
port=19919
# addnode=1.2.3.4:19919
# listen=1
```

## Компилиране от изходен код

Проверени версии: GCC 13.2 (MinGW-w64), Boost 1.83, Berkeley DB 4.8.30,
OpenSSL 1.0.2u, Qt 5.15.2 и вградения LevelDB. Подробната документация е на
английски:

* [Windows](../build-msw.md) - крос-компилация от Linux (x86_64 и i686)
* [Unix](../build-unix.md)
* [macOS](../build-osx.md)
* [Qt портфейл](../readme-qt.rst)

Berkeley DB 4.8 е задължителна: по-новите версии променят формата на файла
`wallet.dat`.
