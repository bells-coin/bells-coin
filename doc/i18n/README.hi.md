# Bells (BEL)

Bells एक विकेंद्रीकृत पीयर-टू-पीयर इलेक्ट्रॉनिक नकदी प्रणाली है, जिसमें
प्रूफ़-ऑफ़-वर्क के लिए **scrypt** एल्गोरिद्म का उपयोग होता है। यह परियोजना
Litecoin का फ़ोर्क है: 2.5 मिनट के ब्लॉक, हर ब्लॉक में कठिनाई का पुनर्गणना
(DigiShield) और कुल आपूर्ति 500,000,000 BEL। संदर्भ क्लाइंट 0.8.7.1 में
`bellsd` डेमन और `bells-qt` ग्राफ़िकल वॉलेट शामिल हैं।

## नेटवर्क पैरामीटर

| पैरामीटर | मान |
| --- | --- |
| प्रूफ़-ऑफ़-वर्क | scrypt |
| लक्षित ब्लॉक समय | 2.5 मिनट |
| कठिनाई पुनर्गणना | हर ब्लॉक (DigiShield) |
| कुल आपूर्ति | 500,000,000 BEL |
| P2P पोर्ट (मुख्य नेटवर्क) | 19919 |
| RPC पोर्ट (मुख्य नेटवर्क) | 19918 |
| टेस्ट नेटवर्क (P2P / RPC) | 29919 / 29918 |
| पता उपसर्ग | `B` |
| प्रोटोकॉल संस्करण | 70002 |
| डेटा निर्देशिका (Windows) | `%APPDATA%\Bells` |
| डेटा निर्देशिका (Unix) | `~/.bells` |
| कॉन्फ़िगरेशन फ़ाइल | `bells.conf` |

## Windows पर त्वरित शुरुआत

1. रिलीज़ पृष्ठ से `bells-0.8.7.1-win64.zip` या `bells-0.8.7.1-win32.zip`
   डाउनलोड करें।
2. संग्रह को एक फ़ोल्डर में खोलें और सभी फ़ाइलें साथ रखें: Qt DLL और
   `platforms` फ़ोल्डर के बिना वॉलेट शुरू नहीं होगा।
3. ग्राफ़िकल वॉलेट के लिए `bells-qt.exe` और कमांड लाइन डेमन के लिए `bellsd.exe`
   चलाएँ।
4. असली धन के साथ वॉलेट उपयोग करने से पहले `wallet.dat` का बैकअप लें। फ़ाइल
   `%APPDATA%\Bells` में है।

डेमन `Ctrl+C` से बंद होता है। Windows में Unix जैसा डेमन मोड नहीं है, इसलिए
`-daemon` विकल्प का कोई प्रभाव नहीं होता; इसके बजाय `start /b bellsd.exe`
उपयोग करें।

## कॉन्फ़िगरेशन

`%APPDATA%\Bells\bells.conf` निम्न सेटिंग्स स्वीकार करता है:

```ini
server=1
rpcuser=user
rpcpassword=change-me
rpcallowip=127.0.0.1
rpcport=19918
port=19919
# addnode=1.2.3.4:19919
# listen=1
```

## स्रोत से बिल्ड करना

परीक्षित संस्करण: GCC 13.2 (MinGW-w64), Boost 1.83, Berkeley DB 4.8.30,
OpenSSL 1.0.2u, Qt 5.15.2 और साथ में दिया गया LevelDB। विस्तृत दस्तावेज़
अंग्रेज़ी में हैं:

* [Windows](../build-msw.md) - Linux से क्रॉस-कंपाइल (x86_64 और i686)
* [Unix](../build-unix.md)
* [macOS](../build-osx.md)
* [Qt वॉलेट](../readme-qt.rst)

Berkeley DB 4.8 अनिवार्य है: नए संस्करण `wallet.dat` का फ़ाइल प्रारूप बदल देते
हैं।
