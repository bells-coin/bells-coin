# Bells (BEL)

Bells ایک غیر مرکزی پیئر ٹو پیئر الیکٹرانک نقدی نظام ہے جس میں پروف آف ورک کے
لیے **scrypt** الگورتھم استعمال ہوتا ہے۔ یہ منصوبہ Litecoin کا فورک ہے: 2.5 منٹ
کے بلاک، ہر بلاک میں مشکل کی دوبارہ گنتی (DigiShield) اور کل سپلائی
500,000,000 BEL۔ حوالہ کلائنٹ 0.8.7.1 میں `bellsd` ڈیمن اور `bells-qt`
گرافیکل والٹ شامل ہیں۔

## نیٹ ورک پیرامیٹرز

| پیرامیٹر | قدر |
| --- | --- |
| پروف آف ورک | scrypt |
| ہدف بلاک وقت | 2.5 منٹ |
| مشکل کی دوبارہ گنتی | ہر بلاک میں (DigiShield) |
| کل سپلائی | 500,000,000 BEL |
| P2P پورٹ (مرکزی نیٹ ورک) | 19919 |
| RPC پورٹ (مرکزی نیٹ ورک) | 19918 |
| ٹیسٹ نیٹ ورک (P2P / RPC) | 29919 / 29918 |
| پتے کا سابقہ | `B` |
| پروٹوکول ورژن | 70002 |
| ڈیٹا ڈائریکٹری (Windows) | `%APPDATA%\Bells` |
| ڈیٹا ڈائریکٹری (Unix) | `~/.bells` |
| کنفیگریشن فائل | `bells.conf` |

## Windows پر فوری آغاز

1. ریلیز صفحے سے `bells-0.8.7.1-win64.zip` یا `bells-0.8.7.1-win32.zip`
   ڈاؤن لوڈ کریں۔
2. آرکائیو کو کسی فولڈر میں کھولیں اور تمام فائلیں ساتھ رکھیں: Qt DLLs اور
   `platforms` فولڈر کے بغیر والٹ شروع نہیں ہوگا۔
3. گرافیکل والٹ کے لیے `bells-qt.exe` اور کمانڈ لائن ڈیمن کے لیے `bellsd.exe`
   چلائیں۔
4. حقیقی رقم کے ساتھ والٹ استعمال کرنے سے پہلے `wallet.dat` کا بیک اپ لیں۔
   فائل `%APPDATA%\Bells` میں موجود ہے۔

ڈیمن `Ctrl+C` سے بند ہوتا ہے۔ Windows میں Unix طرز کا ڈیمن موڈ نہیں ہے، اس لیے
`-daemon` اختیار کا کوئی اثر نہیں؛ اس کے بجائے `start /b bellsd.exe` استعمال
کریں۔

## کنفیگریشن

`%APPDATA%\Bells\bells.conf` درج ذیل ترتیبات قبول کرتا ہے:

```ini
server=1
rpcuser=user
rpcpassword=change-me
rpcallowip=127.0.0.1
rpcport=19918
port=19919
# addnode=1.2.3.4:19919
# listen=1
```

## سورس سے بلڈ کرنا

آزمودہ ورژن: GCC 13.2 (MinGW-w64)، Boost 1.83، Berkeley DB 4.8.30،
OpenSSL 1.0.2u، Qt 5.15.2 اور شامل LevelDB۔ تفصیلی دستاویزات انگریزی میں ہیں:

* [Windows](../build-msw.md) - Linux سے کراس کمپائل (x86_64 اور i686)
* [Unix](../build-unix.md)
* [macOS](../build-osx.md)
* [Qt والٹ](../readme-qt.rst)

Berkeley DB 4.8 لازمی ہے: نئے ورژن `wallet.dat` کی فائل فارمیٹ بدل دیتے ہیں۔
