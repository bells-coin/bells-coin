# Bells (BEL)

بيليز (Bells) نظام نقد إلكتروني لامركزي يعمل من نظير إلى نظير، ويعتمد في إثبات
العمل على خوارزمية **scrypt**. المشروع متفرع من Litecoin: زمن الكتلة 2.5 دقيقة،
وإعادة ضبط الصعوبة في كل كتلة (DigiShield)، وإجمالي المعروض 500,000,000 BEL.
يتضمن العميل المرجعي 0.8.7.1 الخادم `bellsd` والمحفظة الرسومية `bells-qt`.

## معاملات الشبكة

| المعامل | القيمة |
| --- | --- |
| إثبات العمل | scrypt |
| زمن الكتلة المستهدف | 2.5 دقيقة |
| إعادة ضبط الصعوبة | في كل كتلة (DigiShield) |
| إجمالي المعروض | 500,000,000 BEL |
| منفذ P2P (الشبكة الرئيسية) | 19919 |
| منفذ RPC (الشبكة الرئيسية) | 19918 |
| شبكة الاختبار (P2P / RPC) | 29919 / 29918 |
| بادئة العنوان | `B` |
| إصدار البروتوكول | 70002 |
| مجلد البيانات (Windows) | `%APPDATA%\Bells` |
| مجلد البيانات (Unix) | `~/.bells` |
| ملف الإعدادات | `bells.conf` |

## البدء السريع في Windows

1. نزّل `bells-0.8.7.1-win64.zip` أو `bells-0.8.7.1-win32.zip` من صفحة الإصدارات.
2. فك ضغط الأرشيف في مجلد واحد وأبقِ جميع الملفات معًا: لن تعمل المحفظة بدون
   مكتبات Qt ومجلد `platforms`.
3. شغّل `bells-qt.exe` للمحفظة الرسومية أو `bellsd.exe` للخادم من سطر الأوامر.
4. انسخ `wallet.dat` احتياطيًا قبل استخدام المحفظة بأموال حقيقية. يوجد الملف في
   `%APPDATA%\Bells`.

لإيقاف الخادم اضغط `Ctrl+C`. لا يدعم Windows وضع الخادم الخلفي كما في Unix،
لذا لا يؤثر الخيار `-daemon`؛ استخدم `start /b bellsd.exe` بدلًا منه.

## الإعدادات

يقبل الملف `%APPDATA%\Bells\bells.conf` الإعدادات التالية:

```ini
server=1
rpcuser=user
rpcpassword=change-me
rpcallowip=127.0.0.1
rpcport=19918
port=19919
# addnode=1.2.3.4:19919
# listen=1
```

## البناء من المصدر

الإصدارات المجرَّبة: GCC 13.2 (MinGW-w64) وBoost 1.83 وBerkeley DB 4.8.30
وOpenSSL 1.0.2u وQt 5.15.2 وLevelDB المرفق. الوثائق الكاملة متوفرة بالإنجليزية:

* [Windows](../build-msw.md) — بناء متقاطع من Linux (x86_64 وi686)
* [Unix](../build-unix.md)
* [macOS](../build-osx.md)
* [محفظة Qt](../readme-qt.rst)

يجب استخدام Berkeley DB 4.8: الإصدارات الأحدث تغيّر صيغة ملف `wallet.dat`.
