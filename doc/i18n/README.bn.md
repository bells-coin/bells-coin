# Bells (BEL)

Bells হলো একটি বিকেন্দ্রীকৃত পিয়ার-টু-পিয়ার ইলেকট্রনিক নগদ ব্যবস্থা, যেখানে
প্রুফ-অব-ওয়ার্ক হিসেবে **scrypt** অ্যালগরিদম ব্যবহৃত হয়। প্রকল্পটি Litecoin-এর
ফোর্ক: ২.৫ মিনিটের ব্লক, প্রতিটি ব্লকে কঠিনতার পুনঃগণনা (DigiShield) এবং মোট
সরবরাহ ৫০০,০০০,০০০ BEL। রেফারেন্স ক্লায়েন্ট 0.8.7.1-এ `bellsd` ডেমন এবং
`bells-qt` গ্রাফিক্যাল ওয়ালেট রয়েছে।

## নেটওয়ার্ক প্যারামিটার

| প্যারামিটার | মান |
| --- | --- |
| প্রুফ-অব-ওয়ার্ক | scrypt |
| লক্ষ্য ব্লক সময় | ২.৫ মিনিট |
| কঠিনতা পুনঃগণনা | প্রতিটি ব্লকে (DigiShield) |
| মোট সরবরাহ | ৫০০,০০০,০০০ BEL |
| P2P পোর্ট (মূল নেটওয়ার্ক) | 19919 |
| RPC পোর্ট (মূল নেটওয়ার্ক) | 19918 |
| টেস্ট নেটওয়ার্ক (P2P / RPC) | 29919 / 29918 |
| ঠিকানার উপসর্গ | `B` |
| প্রোটোকল সংস্করণ | 70002 |
| ডেটা ডিরেক্টরি (Windows) | `%APPDATA%\Bells` |
| ডেটা ডিরেক্টরি (Unix) | `~/.bells` |
| কনফিগারেশন ফাইল | `bells.conf` |

## Windows-এ দ্রুত শুরু

1. রিলিজ পৃষ্ঠা থেকে `bells-0.8.7.1-win64.zip` অথবা `bells-0.8.7.1-win32.zip`
   ডাউনলোড করুন।
2. আর্কাইভটি একটি ফোল্ডারে খুলুন এবং সব ফাইল একসাথে রাখুন: Qt DLL এবং
   `platforms` ফোল্ডার ছাড়া ওয়ালেট চালু হবে না।
3. গ্রাফিক্যাল ওয়ালেটের জন্য `bells-qt.exe` এবং কমান্ড লাইনের ডেমনের জন্য
   `bellsd.exe` চালান।
4. প্রকৃত অর্থ দিয়ে ওয়ালেট ব্যবহারের আগে `wallet.dat` এর ব্যাকআপ নিন। ফাইলটি
   `%APPDATA%\Bells`-এ থাকে।

ডেমন `Ctrl+C` দিয়ে বন্ধ হয়। Windows-এ Unix-ধাঁচের ডেমন মোড নেই, তাই
`-daemon` অপশনের কোনো প্রভাব নেই; এর বদলে `start /b bellsd.exe` ব্যবহার করুন।

## কনফিগারেশন

`%APPDATA%\Bells\bells.conf` নিম্নলিখিত সেটিংস গ্রহণ করে:

```ini
server=1
rpcuser=user
rpcpassword=change-me
rpcallowip=127.0.0.1
rpcport=19918
port=19919
# addnode=1.2.3.4:19919
# listen=1
```

## সোর্স থেকে বিল্ড

পরীক্ষিত সংস্করণ: GCC 13.2 (MinGW-w64), Boost 1.83, Berkeley DB 4.8.30,
OpenSSL 1.0.2u, Qt 5.15.2 এবং অন্তর্ভুক্ত LevelDB। বিস্তারিত ডকুমেন্টেশন
ইংরেজিতে:

* [Windows](../build-msw.md) - Linux থেকে ক্রস-কম্পাইল (x86_64 এবং i686)
* [Unix](../build-unix.md)
* [macOS](../build-osx.md)
* [Qt ওয়ালেট](../readme-qt.rst)

Berkeley DB 4.8 আবশ্যক: নতুন সংস্করণ `wallet.dat`-এর ফাইল ফরম্যাট পরিবর্তন করে।
